# Mixed Messages

This is a small JavaScript message generator project.

Every time the program runs, it creates a random developer motivation message from three different parts.

## Project Objectives

- Build a message generator program using JavaScript
- Use Git version control
- Use the command line
- Develop locally on my computer
- Use GitHub for remote version control

## Technologies

- JavaScript
- Node.js
- Git
- GitHub
- IntelliJ IDEA

## How to Run

Run the following command in the terminal:

```bash
node script.js
```

## Example Output

```txt
Heute programmierst du mit Fokus, löst ein kniffliges Problem und erinnerst dich: Jeder Bug macht dich besser.
```
